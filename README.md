# Kayfiyat Meme Generatori 😄

365 kunlik ijodiy loyihalar challenge — **23-kun**.

Bugungi kayfiyatingizni tanlang — sizga mos, original (mualliflik huquqisiz, o'zi yaratilgan) meme klassik "Impact" shrift uslubida tayyorlanadi.

## Xususiyatlari

- 8 xil kayfiyat (xursand, g'amgin, charchagan, asabiy, zerikkan, hayajonli, uyqusirab, ishonchli)
- Har bir kayfiyat uchun 3 tadan original matn juftligi va o'ziga xos rang gradienti
- Klassik meme uslubidagi qalin oq-qora konturli matn
- Hech qanday tashqi rasm yoki tayyor shablon ishlatilmagan — hammasi CSS va emoji bilan yaratilgan

## Ishga tushirish

`index.html` faylini brauzerda oching. Hech qanday server yoki kutubxona kerak emas.

## Texnologiyalar

- HTML5 / CSS3 (gradient, text-stroke) / Vanilla JavaScript
